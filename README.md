# Jemmy 的小玩具

## 一笔画小鸭

用鼠标（或手指）一笔描出一只小黄鸭的网页小游戏，单个 HTML 文件，无任何依赖。

- 文件：[`one-stroke-duck/index.html`](one-stroke-duck/index.html)，双击用浏览器打开即可玩。
- 玩法：按住鼠标沿朱红虚线描完整只鸭子，中途松手就算收笔。起点和方向随意。
- 评分：看鸭子描到了多少、笔迹有多少贴在线上。70 分以上鸭子会填色点睛「活过来」，90 分以上撒花。
- 三种玩法：描红（虚线全程可见）、记忆（落笔后虚线消失）、盲画（虚线和笔迹都看不见，松手才揭晓）。
- 每种玩法的最高分记在浏览器本地。

在线玩：<https://jemmychao.github.io/Jemmy/>（GitHub Pages，由 `.github/workflows/pages.yml` 在推送后自动发布）。
